# 🚀 Neon Strike iOS

2D космический шутер для iOS, разработанный на SwiftUI с использованием Canvas API.

## 🎮 Что реализовано

- **Плавная графика 60 FPS** на базе TimelineView и Canvas
- **6 типов боссов** с уникальными паттернами атак:
  - Танк, Скоростной, Телепортер
  - Разделитель (делится при смерти)
  - Щит (нужно уничтожить 4 пушки)
  - Призыватель (спавнит миньонов)
- **Система апгрейдов** между волнами (как в Vampire Survivors)
- **4 типа оружия**: стандарт, дробовик, лазер, самонаведение
- **Система комбо** с множителем очков
- **Магазин скинов** с валютой (кристаллы)
- **Ежедневные задания и награды**
- **Система достижений**
- **Динамическая смена фона** каждые 5 волн
- **Сохранение прогресса** через UserDefaults

## 🛠 Технологии

- **Язык:** Swift 5.9+
- **UI:** SwiftUI, Canvas API
- **Архитектура:** MVVM (@Observable класс GameEngine)
- **Хранение данных:** UserDefaults (Codable)
- **Тактильная отдача:** CoreHaptics
